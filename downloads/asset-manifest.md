# รายการภาพประกอบ

ภาพหน้าจอทั้งหมดถ่ายจาก PortfolioMatch branch `kan/backend` production build ณ 31 ตุลาคม 2569 โดยใช้ข้อมูล mock เริ่มต้น. อนุญาตให้ใช้ประกอบรายงานและสไลด์ของทีม.

- `dashboard.png` — ภาพรวมผู้สมัครและคะแนนตัวอย่าง
- `create-admission.png` — หน้าตั้งค่ารอบรับสมัคร
- `application-form.png` — ฟอร์มผู้สมัคร
- `applicants.png` — รายชื่อผู้สมัคร
- `applicant-detail.png` — รายละเอียดและ Approve/Reject
- `user-flow.svg` — ลำดับการใช้งานเดโม
- `system-architecture.svg` — สถาปัตยกรรมที่มีอยู่จริง
- `scope-map.svg` — สิ่งที่มีในต้นแบบเทียบกับงานพัฒนาต่อ

ข้อควรระบุใต้ภาพ: ตัวเลขและคะแนนเป็นข้อมูล mock; ไม่มีการวิเคราะห์ PDF ด้วย AI จริง. ภาพหน้าจอไม่ได้เป็นหลักฐานว่า QA ทุกกรณีผ่านแล้ว.
